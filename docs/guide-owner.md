# Инструкция для владельца

Выберите «Владелец», введите выданный при серверной настройке PIN и нажмите «Войти». Старые PIN из исходного кода больше не используются.

## Отчёт за дату

«Сегодня», «Вчера» и календарь выбирают день по Москве. «Обновить» запрашивает данные с сервера; автоматическое обновление выполняется каждые две минуты. Строка состояния показывает, получены ли свежие данные или доступна только сохранённая копия.

Общий результат магазина показывает выполнение каждой задачи хотя бы одним сотрудником. Личные карточки показывают действия конкретного сотрудника. Поэтому итог магазина не равен сумме личных карточек.

- «Выполнено» — успешная отметка, в том числе с опозданием.
- «Не выполнено» — сотрудник указал отказ и причину.
- «Без отметки» — результата пока нет.
- «С опозданием» — успешная отметка после дедлайна.

Нажмите карточку сотрудника для подробностей. Причины, время и статусы не скрываются за общим процентом. Статус смены отдельно показывает начало и завершение; отсутствие прихода не считается присутствием на работе.

Журнал покупателей показывает зарегистрированные визиты, сотрудника и время. Это журнал действий сотрудников, а не достоверный счётчик всех посетителей магазина.

## Доступ и настройки

Новый PIN выдаётся серверной процедурой: см. [настройку Supabase](setup-supabase.md). Не храните PIN в GitHub или публичных таблицах. Выдача нового PIN аннулирует прежние сессии профиля.

Список задач задаётся в js/config.js и серверном каталоге supabase/migration.sql. Меняйте оба согласованно. Сохраняйте стабильные ID исторических задач; изменение названий не должно менять смысл старых отчётов.

## Telegram

Дополнительные уведомления требуют отдельной серверной настройки: [инструкция](setup-telegram.md). Источником истины остаётся сохранённый отчёт в панели. Автоматические напоминания перед дедлайном и отчёты о пропуске смены в этой версии не реализованы.

Если записи не появились, проверьте статус сервера и дату. Не удаляйте рабочие строки для «сброса дня»: новый день открывается автоматически, история сохраняется.
