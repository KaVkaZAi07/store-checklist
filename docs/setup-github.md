# Публикация на GitHub Pages

Приложение — статический сайт. GitHub Pages публикует HTML, CSS, JavaScript и иконки; база находится в Supabase.

1. Сначала настройте [Supabase](setup-supabase.md), новые PIN и проверьте RPC.
2. Выполните npm ci --ignore-scripts, npm test и npm run test:e2e (Chromium устанавливается командой npx playwright install chromium).
3. Проверьте подготовленный pull request и объедините его в публикуемую ветку.
4. В Settings → Pages выберите нужную ветку и корневую папку, если Pages ещё не настроен. Сборка не требуется.
5. Откройте сайт, проверьте вход сотрудника и владельца, сохранение, обновление и работу на телефоне.
6. Для обновления PWA дождитесь загрузки новой версии и перезапустите приложение. Service Worker очищает только кэши этого чеклиста.

Не публикуйте .env, тестовые артефакты, локальную базу или файл с выданными PIN. Публикуемый код содержит только URL Supabase и публичный API-ключ.

Нельзя публиковать новый клиент до настройки серверной схемы: в этом случае он покажет ошибку настройки и не разрешит вход. Нельзя возвращать старый клиент после закрытия анонимного доступа к таблицам.
